# LE VOCI DELL'EPICA — Quiz di classe

Quiz multiplayer di quattro domande tratte dalla verifica «Le voci dell’epica». Identità grafica da `halmob01/epica-romanzo`: Alfa Slab One, Public Sans, prugna e carta chiara.

**Stato:** progetto iniziale. La modalità in diretta richiede la configurazione di Firebase Realtime Database e delle regole di sicurezza; GitHub Pages da solo non può sincronizzare le risposte di telefoni diversi.

Documentazione di installazione e uso sarà completata insieme al primo incremento.
